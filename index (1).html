The Game

What is Hyper Space Shooter?

01 🚀

Arcade Action

Pilot your ship, dodge enemy fire, and destroy wave after wave of enemies.

02 🤖

Enemy AI

4 enemy types with distinct behaviors — weavers, tanks, swifts, and bombers.

03 💥

Boss Battles

Every wave ends with a Boss that has 3 attack phases scaling with your level.

04 ⚡

Power-Ups

5 collectible power-ups — rapid fire, triple shot, laser beam, shield, and bomb.

05 ✨

Particle FX

Explosions, engine trails, screen shake, and a scrolling 140-star parallax field.

06 🎮

Smooth 60 FPS

Double-buffered rendering via BufferedImage with a Swing Timer game loop.

Technical Design

Project Architecture

engine — core logic
GameWorld.java InputHandler.java ParticleSystem.java Starfield.java
entities — game objects
Player.java Enemy.java Bullet.java
ui — rendering
GameWindow.java GamePanel.java Renderer.java GameScreen.java
powerups & util
PowerUp.java PowerUpType.java Constants.java Utils.java
Game logic and rendering are fully separated — GameWorld never touches Graphics2D, and Renderer contains zero game logic. Clean MVC-style architecture using only the Java standard library.
